# TEMPUS

Личный офлайн-планировщик и летопись для Android. Интерфейс на русском языке, суммы в тенге.

- **Сегодня** — задачи, привычки, выполнение за день и быстрый вход в дневник.
- **План** — месячный календарь, повторение по дням недели, месячные цели и напоминания.
- **Прогресс** — план и выполнение за неделю, месяц или год, счётчики целей, история отметок, график по времени и разбивка по сферам. Годовой отчёт можно сохранить в PDF.
- **Летопись** — дневник, события, книги, театр, ремесло, достижения и восстановление. В летописи записи сгруппированы по месяцам. У записей есть поиск, категории, заметки и фотообложки.
- **Финансы** — доходы, расходы и баланс за месяц. Открываются из летописи.
- **Профиль** — имя и начало годовой истории. По умолчанию история начинается 1 августа 2026 года. Можно добавлять записи задним числом.

## Запуск и сборка

Нужны Flutter 3.50.1, JDK 17 или 21 и платформы Android SDK 35 и 36. Минимальная версия устройства — Android 7.0 (API 24).

```sh
flutter pub get
flutter analyze
flutter test
flutter run
flutter build apk --release --target-platform android-arm64
```

APK находится в `build/app/outputs/flutter-apk/app-release.apk`. Для сборки под все поддерживаемые архитектуры убери `--target-platform android-arm64`.

Для постоянной подписи создай собственный Android-ключ. Укажи в локальном `android/key.properties` значения `storeFile`, `storePassword`, `keyAlias` и `keyPassword`. Путь `storeFile` может быть абсолютным или относительным к каталогу `android`. Без файла настроек APK подписывается отладочным ключом для установки и проверки. Для обновления поверх установленной версии Android требует прежний ключ подписи.

## Хранение данных

TEMPUS использует SQLite через Drift. Записи и фотографии остаются в каталоге приложения. Сервер, регистрация и интернет для работы приложения не нужны.

При обновлении с версии 1.0 записи, фотографии и настройки хранятся в той же SQLite-базе. Для старых целей число повторов извлекается из названия, если оно там указано. Прежняя галочка у завершённой цели переносится как выполнение её плана.

Android запрашивает разрешение на уведомления, когда создаётся первое напоминание. Напоминания могут приходить позже заданного времени в зависимости от режима энергосбережения устройства.
